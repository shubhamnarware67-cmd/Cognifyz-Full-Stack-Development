# Shubham's API Notebook — Cognifyz Task 5

A full-stack notes interface backed by a small RESTful CRUD API.

## Task coverage

- `GET /api/notes` lists notes
- `POST /api/notes` creates a note
- `PATCH /api/notes/:id` updates a note
- `DELETE /api/notes/:id` removes a note
- Front-end uses `fetch()` for every API interaction
- Validation and useful HTTP status codes
- Responsive UI with create/edit dialog and delete action

## Run

```bash
npm install
npm start
```

Open `http://localhost:3005`.
