# Shubham's Feedback Desk — Cognifyz Task 2

Task 2 extends the first form with inline JavaScript interaction, stronger server-side validation, and temporary server-side storage.

## Highlights

- Client-side character count and submit guard
- Server-side validation for name, email, topic, and message length
- Validation errors are shown without losing the user's input
- Valid submissions are kept in an in-memory inbox at `/submissions`
- Responsive hand-crafted UI

## Run

```bash
npm install
npm start
```

Open `http://localhost:3002`.
