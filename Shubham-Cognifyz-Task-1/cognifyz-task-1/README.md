# Shubham's Guestbook — Cognifyz Task 1

This is a small server-rendered guestbook built for the Full Stack Development internship task.

## What is included

- Semantic HTML form for name, email, and message
- Express server with a `POST /submit` endpoint
- EJS server-side rendering
- Friendly server-side required-field validation
- A responsive, hand-styled interface

## Run locally

```bash
npm install
npm start
```

Open `http://localhost:3001`.
