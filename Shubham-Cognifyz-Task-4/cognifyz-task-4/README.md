# Shubham's Account Lab — Cognifyz Task 4

An interactive front-end form demonstrating complex validation and dynamic DOM manipulation.

## Task coverage

- Password strength rules: length, case, number, and symbol
- Matching password and terms validation
- Inline field errors and dynamic strength meter
- Show/hide password interaction
- Hash-based client-side routing between Join and About screens
- Success state and reset flow without a page reload

## Run

```bash
npm install
npm start
```

Open `http://localhost:3004`.
